# Project 3: AI Recommendation Logic

## Overview
A simple preference-based recommendation system built with Python.

## Requirements
- Take user interests as input
- Match preferences using logic and pattern matching
- Display recommended items

## Skills
- Logic building
- Pattern matching
- User input handling
- Lists and dictionaries
- Recommendation concepts

## Run
```bash
python main.py
```

## Example
```text
Enter your interests (comma-separated) or 'exit': technology, books

Recommended for you:
1. Python Programming Course
2. AI Fundamentals
3. Web Development Course
4. Python Programming Book
5. Artificial Intelligence Book
6. Software Engineering Book
```

## Available Interests
technology, gaming, music, sports, books, business

## Note
This is an educational, rule-based recommendation system using predefined preferences. It does not use a trained machine-learning model.
